# radar-licitacoes

Receba automaticamente alertas de editais públicos com base nas palavras-chave que interessam ao seu negócio.

## 🚨 O Problema

Empresas que vendem para o governo precisam acompanhar diariamente dezenas de portais de compras públicas.  
Mas os filtros são ruins, a navegação é confusa, e é fácil perder uma oportunidade por falta de atenção.

Esse projeto resolve isso de forma simples: automatiza a busca por editais relevantes e envia alertas diários com base em palavras-chave configuradas pelo usuário.
